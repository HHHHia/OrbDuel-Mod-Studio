## 4. 每日节奏

- 早上 10 分钟：读 `docs/STATUS.md`，认领当天卡片；
- 每天至少一个能编译的 commit（哪怕只是空实现 + 注释）；
- 晚上合并前：`build.ps1 -SkipRun` + `validate_content.ps1` 两条绿；
- 周五阶段验收，不达标就砍功能，不加时。

## 6. 风险

| 风险 | 概率 | 应对 |
|---|---|---|
| 队友环境装不上 | 中 | 依赖已离线；实在不行让 B 出 exe，其他人只改内容 |
| 物理穿模 / 球卡墙 | 中 | `maxSpeed` 上限 + `resolveOverlaps` 每步执行 |
| 三个人同时改 `types.hpp` | 高 | 该文件冻结，改动必须先说 |
| 热重载引发生命周期 bug（贴图释放后还用） | 中 | 重载只换数据，纹理用句柄 + 引用计数，晚一帧生效 |
| 演示现场没网 | 高 | 依赖离线；演示只用本地仓库 |
