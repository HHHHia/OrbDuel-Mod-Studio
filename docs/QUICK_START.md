# 开始使用

双击同目录下的 `orbduel.exe`。

- 地图编辑器：放置、拖动机关，在右侧修改参数；传送门需要选择另一个门作为出口。
- 打开 / 另存：选择五套内置示例地图，或保存自己的场地。
- 测试地图：运行自动对战，结束后返回编辑器继续修改。
- 分享码：复制或粘贴完整地图配置。接收者需要另行复制相同的模组文件夹。
- 模组工坊：查看和重新加载模组；作者教程在 `docs/MOD_STUDIO.md`。

五套风格：星空、地下城、霓虹都市、熔岩遗迹、冰晶圣殿。

当前版本是可试玩的创作基础版，角色数值可在编辑器中继续调整。

整合版提供九个角色、十六技能，包含疾锋、黑洞和木人桩。主页可以直接换角色，技能说明、蓄力状态和冷却会显示在面板中；身体穿透、挨撞系数与质量成长在角色属性的“身体与成长”里调整。旧地图若要采用当前预设，请点“应用预设”，自定义数值不会被自动覆盖。当前跨角色强弱差异较大，详见 docs/BALANCE.md。
