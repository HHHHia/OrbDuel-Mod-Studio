# 默认竞技角色与接触伤害平衡

本轮只统计八个竞技角色。木人桩通过角色根级 competitive=false 标记为训练对象，仍可在游戏中选择；统计工具按字段筛选，没有写死角色名单。

## 修正规则

- 角色缺省 contact=1，避免漏填字段变成普通碰撞免伤。
- 普通碰撞倍率 = 地图 damageScale × 挨撞角色 contact。任一显式为 0 时关闭该方普通碰撞；基础地图默认 damageScale=1。
- 攻击使用各自碰撞前朝向对手的速度，倍率为 clamp(0.5+speed/refSpeed,0.5,2.5)，保留三秒连击窗口与 2.5 上限，再应用攻击增益、护甲、护盾。
- ghost 仅控制物理穿入；蓄力重击、贯穿、引力及模组主动伤害独立结算。万向天引仍保留自身无敌、双方普通碰撞关闭及被动抑制。

## 数据与验收

调参种子为 1000–1063；最终独立验证为 90000–90127，每类场地 128 个种子、28 对角色、交换左右位置、四类场地，共 **28672 局**。空场无机关或障碍；其余分别使用三对镜像障碍、三组原生机关，以及机关加缩圈。所有配置使用 60 秒上限，来自实际 Simulation 与 DLL，没有替代公式。

修复前对照使用同一分支起点的原规则与数值、排除训练角色，种子 90000–90031，共 7168 局。前后样本量不同，表中均为各自完整样本的得分率。原始数据见 [修复前](balance/contact-before.json) 与 [最终验证](balance/competitive.json)；最终报告包含角色参数、完整技能定义、场景规则与对阵分项。

## 主要数值调整与保留机制

- 疾锋：HP 150→103，普通攻击 12→10，蓄力重击系数 0.12→0.04，贯穿伤害 8→6。保留 500 释放速度、学习缩短、瞄准学习、打断/抗打断和单次贯穿推力机制。
- 黑洞：HP 250→155，普通攻击 12→7；核心伤害 6–24→3–12，场域 DPS 1–8→0.2–1.6；大招冷却 8→12 秒、爆炸 22–60→12–30、场内 DPS 1–3→0–0.6。
- 黑洞的 ghost、0.6 接触抗性、2.6→5 质量成长、引力范围与加速度成长、核心安全传送/保护、大招无敌/被动抑制/爆炸后冷却均保留。大招时长仍随时间成长。
- 其余六个竞技角色及其技能数值保持不变。木人桩数值不调，只移出竞技统计。

## 重跑

先构建，再执行：

```powershell
.\build.ps1 -SkipRun
ctest --test-dir build -C Release --output-on-failure
.\build\Release\orbduel_balance.exe content build/bin/mods build/balance/competitive.json 128 90000
```

CTest 包括工作台、特色机制、接触规则与一轮八角色循环赛冒烟测试。最终统计针对上述一分钟默认规则；无限时长、额外模组、自定义数值和新场地仍需要单独测量，不承诺统一平衡。

内置示例已同步中性身体字段。玩家存档不自动改写：缺少 contact 时采用 1，显式的 0 仍保留；要切换到本轮数值请点击“应用预设”。
